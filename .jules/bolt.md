## 2025-02-28 - Fast-path Unshadowed DOM Method and Property Lookups
**Learning:** DOM reflection functions (`Object.getPrototypeOf` + `Object.getOwnPropertyDescriptor` loops) used to prevent DOM clobbering are expensive when executed thousands of times during DOM traversal. Since 99.99%+ of DOM nodes do not shadow instance methods/getters, checking `!Object.prototype.hasOwnProperty.call(element, prop)` enables an $O(1)$ direct access fast-path for clean elements while preserving full clobbering resistance for shadowed ones. For methods, ensure `!(methodName in Object.prototype)` so built-in `Object.prototype` properties aren't accidentally returned for objects that don't own them.
**Action:** Always check instance-level own property ownership (`Object.prototype.hasOwnProperty.call`) before falling back to multi-level prototype chain traversal for DOM security helpers.
