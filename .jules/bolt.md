## 2025-05-20 - Combined Selector Matching & Guarded Attribute Removal
**Learning:** In event handlers called on every page event (e.g. `preventDefault` / `stopPropagation` interdictions), calling `item.matches(selectorA) || item.matches(selectorB)` for each element in `event.composedPath()` doubles the JS-to-C++ DOM bindings compared to `item.matches("selectorA, selectorB")`. Additionally, `node.removeAttribute(attr)` invokes browser DOM attribute mutation routines even when attributes are missing; checking `node.hasAttribute(attr)` first avoids unnecessary browser work during DOM tree scrubbing.
**Action:** Combine CSS selector constants used in `composedPath()` traversals into a single combined selector string, and always check `node.hasAttribute(attr)` before calling `node.removeAttribute(attr)` in DOM cleaning hot paths.
