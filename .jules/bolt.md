## 2025-02-23 - Fast-path composedPath and Node filtering in DOM Mutation Observers
**Learning:** `event.composedPath()` traverses the entire DOM hierarchy from event target to window. In event interceptors like `isInteractiveEvent`, falling through to `isInteractiveNode(target)` after `composedPath()` finishes causes redundant DOM `closest()` ancestor traversals for every non-interactive event (~35% unnecessary overhead). Additionally, `MutationObserver` childList mutations contain non-Element nodes (Text, Comment) which consume queue slots and delay DOM scrubbing if not filtered (`node.nodeType === 1`) before enqueueing.
**Action:** Always return early when `composedPath()` finishes inspecting all ancestors, and filter `node.nodeType === 1` when queuing added nodes in MutationObserver callbacks.
