3-Step Safari Activation Guide
1
Enable Web Developer Features

Safari → Settings (⌘,) → Advanced → Check "Show features for web developers".

2
Allow Unsigned Extensions

Safari top menu bar → Develop → Check "Allow Unsigned Extensions" (enter Touch ID/password).

3
Set Permissions to Always Allow

Safari → Settings → Extensions → Enable Right Click Restorer & choose "Always Allow on Every Website".
